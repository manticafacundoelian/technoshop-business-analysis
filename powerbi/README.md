# Power BI — Modelado y Visualización

## Modelo de datos

El reporte utiliza un modelo dimensional en estrella compuesto por:

- `fact_pedidos_final`
- `dim_productos`
- `dim_clientes`
- `dim_calendario`

## Medidas y lógica DAX

Principales grupos de medidas:
- Revenue y descuentos
- Costos y rentabilidad
- Ticket promedio
- Variaciones YoY
- Clasificación y segmentación
- Retención y comportamiento de clientes
